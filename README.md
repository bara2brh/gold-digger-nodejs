# Gold Investing App Prototype

A simple gold investing prototype application built with Node.js that displays live gold prices using Server-Sent Events (SSE) and logs user purchases.

---

## Features

- Live gold price updates using SSE
- Simulated gold investment purchases
- Purchase history logging
- Stores:
  - purchase amount
  - gold price at purchase time
  - gold sold in ounces
  - date and time of transaction
- Clean and organized project structure
- Vanilla JavaScript frontend
- Node.js backend without frameworks

---

## Tech Stack

- Node.js
- Vanilla JavaScript
- Server-Sent Events (SSE)
- HTML/CSS
